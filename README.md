# podhorak.cz

Web Okrašlovacího spolku Podhorák a moštárny Dolní Novosedly. Statický web pro GitHub Pages.

## Co kde je
- `index.html` – úvodní stránka spolku
- `mostarna/index.html` – moštárna (termíny, FAQ, rezervace, mapa)
- `sezona.js` – **termíny moštárny, každý rok se mění jen tady**
- `style.css` – vzhled
- `img/` – fotky

## Nová sezóna
Otevři `sezona.js`, přepiš rok a data v `terminy` a ulož (Commit). Za minutu je to na webu.
